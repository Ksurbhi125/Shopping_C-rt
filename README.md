🛒 Shopping Cart Web Application – Java Servlets & JSP

This project allows users to search books by category, add them to cart, view the cart, remove items, and place an order.
It demonstrates Servlet–JSP communication, MVC architecture, and session-based cart management.

✨ Features

Search books by category-
-Add to cart
-View cart
-Remove items from cart
-Place order with success message

🔧 Tech Used

Java · JSP · Servlets · HTML · CSS · Apache Tomcat · HTTP Session
